## Answer

✅ **A. OR = 1011011, XOR = 0011010, AND = 1000001**

### Explanation

```
a = 1010011
b = 1001001
```

### OR (`|`)

A bit is **1 if either bit is 1**.

```text
1010011
1001001
-------
1011011
```

### XOR (`^`)

A bit is **1 if the bits are different**.

```text
1010011
1001001
-------
0011010
```

### AND (`&`)

A bit is **1 only if both bits are 1**.

```text
1010011
1001001
-------
1000001
```

Therefore,

- OR = **1011011**
- XOR = **0011010**
- AND = **1000001**

**Answer:** **Option A**
